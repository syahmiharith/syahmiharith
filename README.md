## Selected work

### 01 · [SplitFlow](https://github.com/syahmiharith/splitflow)

Agree on shared costs before anyone pays. Changed shares require reconfirmation.

[Readiness regressions](https://github.com/syahmiharith/splitflow/commit/929425f9242f78ff357c054bf807a614424d92b0) cover claimed and disputed payments. Interactive prototype; no real money moves.

[Try demo](https://splitflow-xi.vercel.app/) · [Read case study](https://zsyahmi.dev/work/splitflow)

### 02 · [Receipt-to-Form](https://github.com/syahmiharith/receipt-to-form)

Check editable expenses beside the original receipt, then export the corrected records.

A [validation upgrade](https://github.com/syahmiharith/receipt-to-form/commit/556d3d93ad4be6bb8a889adfc025afa6310c8240) covers missing amounts and malformed provider values.

[Try demo](https://receipt-to-form-syahmiharith.vercel.app/) · [Read case study](https://zsyahmi.dev/work/receipt-to-form)

### 03 · [Inventory Request System](https://github.com/syahmiharith/inventory-request-system)

Request supplies, approve them and issue stock. Approval leaves stock unchanged; issuance rechecks availability.

[Fulfillment tests](https://github.com/syahmiharith/inventory-request-system/blob/00d4dacec0d3265c3dfa14a8c4358f86b9653e2d/tests/integration/fulfill-request.test.ts) cover shortages, transaction rollback and repeat issuance.

[Try demo](https://inventory-request-system-syahmiharith.vercel.app/) · [Read case study](https://zsyahmi.dev/work/inventory-request-system)
